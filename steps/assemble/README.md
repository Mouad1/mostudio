# assemble

Renders the final video once from the edit list: video-only cut in batches, preset size, burned captions, mixed audio. Outputs `renders/final.mp4` and `renders/final.srt`.

- **Inputs:** `media/ingest.json` (displayed `width`/`height`, `fps`), `cut/edl.json`, `audio/mix.wav`, `captions/captions.ass`, `captions/captions.srt`, `captions/cues.json` (for the HyperFrames captions).
- **Params:** `preset` (`source` default = ingest size rounded to even, `youtube` 1920x1080, `shorts`/`reels`/`tiktok` 1080x1920), `burnCaptions` (default true; false = no captions), `captionsRenderer` (`ass` | `hyperframes`; default `hyperframes` for shorts/reels/tiktok when the cut is ≤ 180 s, else `ass`).
- **Cut:** keeps are clamped to the source duration like `mix`. First one constant-frame-rate, video-only intermediate of the source, `cache/assemble/cfr.mp4` (`setpts` shifted by the audio stream's start offset in the file, since keep times are on the audio clock that mix re-zeroes; then `fps=<fps>:start_time=0`, so every grid time from 0 has a frame and VFR gaps hold the previous frame). Then batches of ≤ 60 keeps from it, one ffmpeg each (`-ss` input seek to the batch, per keep `trim` to the grid frames nearest its ends, clone-pad, cut to exactly its frame count, `concat`), video only, source resolution, to `cache/assemble/batch-NNN.mp4`. Frame counts follow the cumulative cut time (`round(O_i * fps)`), so every video cut is within half a frame of the matching audio cut and nothing drifts over many keeps. Batches are joined with the concat demuxer (`-c copy`) to `cache/assemble/cut.mp4`. (`MOSTUDIO_ASSEMBLE_BATCH` overrides the batch size; tests only.)
- **Final pass (`ass` / no captions):** `fps=<ingest fps, 2 decimals>,scale=W:H:force_original_aspect_ratio=decrease,pad=W:H:(ow-iw)/2:(oh-ih)/2:black,setsar=1[,ass=filename=<escaped>]`, `-fps_mode cfr`, `audio/mix.wav` as AAC 192 kb/s, `-t outDurationSec`, `-movflags +faststart`. The `ass` path is escaped for both ffmpeg parsing levels (`escapeFilterPath`), so spaces, accents and `'` in the project path work. Before burning, `PlayResX/PlayResY` of `captions.ass` must match the output aspect within 1%, else it fails with `captions.ass is <X>x<Y> but output is <W>x<H>: re-run captions with --param width=<W> --param height=<H>`.
- **Final pass (`hyperframes`):** the cut is rendered at preset size (same filters, no captions, no audio) and moved to `scenes/captions/assets/cut.mp4`; `scenes/captions/` gets `index.html` (the background `<video>` and one captions host, `data-track-kind="captions"`), `compositions/captions.html` (from `components/captions-karaoke/`, one group per cue, word-by-word `#FFD400` highlight with the Web Animations API, no GSAP, no URLs) and `hyperframes.json`. Then `<hf> lint` and `<hf> render --quality looks --fps <fps> -o cache/assemble/captioned.mp4`, where `<hf>` is `MOSTUDIO_HYPERFRAMES_BIN` (a JSON array of strings, e.g. `["/path with space/hf"]`, or split on whitespace) or `npx --yes hyperframes@0.9.26`. A render more than 0.1 s off the cut length fails. The video is stream-copied and muxed with `audio/mix.wav` (AAC 192k). `scenes/captions/` is regenerated on every run and left in place for preview; files there that assemble did not write are named in a log warning before they are removed.
- **Encoder:** `h264_videotoolbox` (`-q:v 70` intermediates / `60` final) or `libx264` (`-crf 12` / `18`, `-preset veryfast`); `MOSTUDIO_ENCODER=libx264` forces software. Always yuv420p.
- **ffmpeg:** needs `ass` only for the `ass` renderer; without libass the error ends with "brew install ffmpeg-full (or use --param captionsRenderer=hyperframes)". `cache/assemble/` is wiped before and after.
- **Metrics:** `durationSec`, `durationDeltaSec` (|final − edl.outDurationSec|), `avOffsetMs` (|first audio pts − first video pts|; AAC priming is about 21 ms), `width, height, fps, batches, captionsBurned, captionsRenderer` (`ass` | `hyperframes` | `none`), `encoder`, `renderSec`. **Gate:** `avOffsetMs <= 40` fail, `durationDeltaSec <= 0.5` fail.
```
mostudio step assemble --project <dir> [--param preset=shorts] [--param captionsRenderer=ass] [--param burnCaptions=false]
```
