# Licenses

This folder contains the open-source licenses and build notices for mostudio and its bundled third-party runtimes:

1. **mostudio** (`mostudio-LICENSE`): MIT License.
2. **Node.js** (`node-LICENSE`): Official Node.js binary distribution license.
3. **FFmpeg & FFprobe** (`ffmpeg-COPYING`): GNU General Public License (GPLv3).
   - `ffmpeg-BUILD.txt` identifies the runtime and its source materials.
   - The controlled Apple Silicon build includes full license texts here. Its accompanying source archive contains the build recipe and exact pinned sources for FFmpeg, FFprobe, and their linked libraries.
   - The legacy local build saves the upstream FFmpeg tarball beside the ZIP for development use.
