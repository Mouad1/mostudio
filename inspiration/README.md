# Inspiration & Creative References

This directory is designed for collecting creative references, style benchmarks, and video ideas to guide video editing in `mostudio`.

## Directory Structure

```
inspiration/
├── README.md
├── shorts/
│   └── links.txt     # URLs for short-form vertical videos (Instagram Reels, YouTube Shorts, TikToks)
└── long/
    └── links.txt     # URLs for long-form landscape videos (YouTube, interviews, podcasts)
```

## Adding References

- **Link Collections:** In `shorts/links.txt` or `long/links.txt`, add one URL per line. Lines starting with `#` are treated as comments or notes (e.g., `# Great hook pacing`).
- **Style Notes & Transcripts:** Add markdown or text files describing pacing, hook structures, visual styles, sound effects, or color grading notes.
- **Reference Media:** If you store audio or video clips locally for style reference, place them in an ignored folder or subfolder. Binary video files (`*.mp4`, `*.mov`, etc.) are ignored by git to keep the repository lightweight.
